# Security

Never publish API keys, access tokens, device identifiers tied to real users, precise end-user location traces, real building calibration profiles, internal Fusion architecture or private diagnostics.

Report a security concern privately via the [IGC Navigation contact page](https://igcnav.com/contact.html). Avoid opening a public issue containing exploit details or secrets.

The examples contain no working credentials. Set keys in environment variables and review permissions before running requests.
